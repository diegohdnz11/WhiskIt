# The Recipe Book

A Recipe Search app that uses TheMealDB Api to find recipes, view recipe details, and lets you save favorites recipies while browsing.

## Requirements

- Flutter SDK installed
- Android Studio, Xcode, Chrome, or another Flutter-supported run target
- Internet access on  device running the app

## Setup

From the project folder:

```bash
flutter pub get
```

Check available devices and connect your device

Run the app:

```bash
flutter run
```

## How to Access the App

1. Start an emulator, simulator or connect a physical device.
2. Make sure that device target has internet access.
3. Run `flutter run` from this project folder.
4. Type a recipe search term, such as `chicken`, `pasta`, or `beef`.
7. Tap the heart icon to add recipe to favorites.
